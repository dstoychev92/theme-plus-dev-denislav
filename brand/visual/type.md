# Type

All four font roles use Figtree: `font_family_heading`, `font_family_subheading`,
`font_family_body`, and `font_family_accent`, at different weights.

- H1, H2, H3, H5, and H6 are uppercase (`type_uppercase_h*`). H4 is not.
- H5 and H6 use the accent font (`type_font_h5`, `type_font_h6`).
- Section titles use the accent font at the H2 preset (`type_font_section`, `type_preset_section`), not uppercase.
- Kickers use the subheading font (`type_font_kicker`), not uppercase.
- Buttons use the accent font, uppercase (`type_font_button`, `type_uppercase_button`).
- Scale: `font_scaling_system` is the small system. No font size adjustments.

Rule: keep one family. Contrast comes from weight and case, not from a second typeface.
