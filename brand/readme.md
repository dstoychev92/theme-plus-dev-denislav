# Brand: theme-plus-dev-denislav

1. A development store for Analog. It has test products and no real audience.
2. The brand is Analog's stock look, as the live theme "denislav-analog" sets it. Nothing here is invented.
3. Type: Figtree in all four font roles. Headings H1–H3 and buttons are uppercase.
4. Shape: pill buttons, pill form fields, small card corners, circle swatches.
5. The sandbox does not exist yet: Analog 1.1.0-beta.3 and earlier have no brand page.

| Read | For |
|---|---|
| `facts.md` | What the store sells, the evidence on hand, and what never to claim |
| `visual/type.md` | Font roles and type settings |
| `visual/layout.md` | Spacing, width, radii, and component styles |

Not written yet: `delight.md`, `verbal/`, the sandbox, and `visual/tokens.css`. A test store has no
voice or audience to extract. Write them when the store gets real products, or when Analog ships the
brand page.
