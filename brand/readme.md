# Boom Coffee brand

1. BOOM! makes functional instant coffee: protein for the body, adaptogens for the mind.
2. It speaks Bulgarian (plus Greek and Romanian markets) to busy, active adults, on first-name terms.
3. Warm cream and coffee brown, with orange, red and blue as the BOOM! accents, each in its own band.
4. Heading Now (bold capitals) for headings, Jost for body, EB Garamond italic as the accent. Custom fonts from the store's Files.
5. Signature: the "Before / with BOOM!" pair. Thread for the delight: the first cup.

Status: extracted from the live Pipeline theme for the move to Analog. Not confirmed by the
client. Analog 1.1.0-beta.3 has no brand page, so there is no sandbox. The values stay in
Theme Settings; `visual/theme-settings.json` and `visual/tokens.css` hold the extracted copy.
